🎯 Problem Statement

Why ContactHub?

Managing personal and professional contacts is fragmented across phone books, spreadsheets, CRMs, and social apps. None are purpose-built for individuals who need fast search, rich tagging, and relationship context at a glance.

😤

Pain Points

  • ✕ Contacts scattered across multiple apps
  • ✕ No way to track relationship context
  • ✕ Slow search on large contact lists
  • ✕ Poor mobile and desktop UI
  • ✕ No tagging or custom categorization
🚀

Our Solution

  • ✓ Single source of truth for all contacts
  • ✓ Notes and relationship timeline
  • ✓ Redis-powered sub-millisecond search
  • ✓ Beautiful responsive glassmorphism UI
  • ✓ Flexible tag and group system
👥 Target Users

Who Is This For?

💼

Professionals

Track clients, partners, and leads with context notes and last-contact dates.

🎓

Students & Networkers

Build and maintain professional networks from conferences, classes, and events.

🏡

Personal Use

Organize family, friends, and personal contacts beyond what a phone app offers.

🏢

Small Teams

Share a central contact list across a small team with role-based views.

✨ Features

Core Feature Set

All features are categorized by priority: P1 (must-have), P2 (should-have), P3 (nice-to-have).

🔍

Instant Search

Full-text search powered by Redis SEARCH — find any contact in under 50ms.

● P1 — Must Have
👤

Rich Contact Profiles

Name, photo, email, phone, company, job title, social links, birthday, address.

● P1 — Must Have
🏷️

Tag & Group System

Create custom tags (e.g., "client", "college") and group contacts by category.

● P1 — Must Have
📝

Notes & Timeline

Add timestamped notes to track conversations and relationship history.

● P1 — Must Have
⭐

Favorites & Pinning

Pin important contacts to the top for instant access.

● P1 — Must Have
📤

Import / Export

Import from CSV / vCard and export your full contact list at any time.

● P2 — Should Have
🔔

Reminders

Set follow-up reminders — "Reach out to Sarah in 2 weeks."

● P2 — Should Have
📊

Analytics Dashboard

See your network stats — contacts added, top tags, activity over time.

● P2 — Should Have
🔗

Relationship Links

Link contacts to each other ("Alex introduced me to Sarah").

● P2 — Should Have
📱

Mobile Responsive

Full feature parity on mobile with touch-optimized interactions.

● P1 — Must Have
🌙

Dark Mode

Seamless dark/light toggle with persisted preference.

● P3 — Nice to Have
🤝

Contact Sharing

Share a contact card via link or QR code.

● P3 — Nice to Have

🎬 Motion Design

Animation Language

All animations are subtle, purposeful, and accessible. Duration: 200–400ms. Easing: ease-in-out or spring.

🃏

Float

Idle contact cards — creates sense of depth. 3s loop.

🔔

Pulse Ring

Notification indicators and follow-up reminders.

✨

Morph

Border radius shape-shift for loading and success states.

💫

Shimmer

Skeleton loader while contacts are being fetched from Redis.

→

Slide In

Detail panels entering from right. New contacts added to list.

🎯

Scale Bounce

Button press feedback and card selection confirmation.

⚙️ Technical Architecture

Tech Stack

🗄️
Redis

Primary datastore, full-text search via RediSearch

⚡
Node.js / Bun

Backend API server with REST endpoints

▲
Next.js / React

Frontend framework with SSR for fast loads

💨
Tailwind CSS

Utility-first styling with custom design tokens

🔐
Auth (NextAuth)

OAuth + session-based auth for multi-user support

☁️
Redis Cloud

Managed Redis with persistence and backups

Data Model

Redis Key Schema
contact:{id} → Hash contacts:all → Sorted Set contacts:tag:{tag} → Set contacts:fav → Set notes:{contactId} → List search:idx → RediSearch
Contact Hash Fields
id, name, email, phone company, title, avatar tags[], birthday, address linkedin, twitter, github notes[], createdAt, updatedAt
